How the value is modelled

  • Multiple — the live market's own price: median market-cap / TVL of the protocols in the same category that already trade. A category with fewer than 3 live protocols falls back to the global median; with no live market at all, 0.5.
  • Maturity — how long the protocol has run with no token: 0.7 on day one, rising to 1.0 after three years listed. A protocol with no listed date scores 0.7.
  • Growth — the seven-day TVL change, clipped to −50%…+100% so one wild week cannot decide a rank, then weighted by half.
  • Breadth — one more chain is worth 5%: 1 + 0.05 × chains, capped at five chains.
  • Floor and cap — no implied value below $1M or above $100B, so a thin protocol cannot rank on noise and a giant cannot run away with the board.
